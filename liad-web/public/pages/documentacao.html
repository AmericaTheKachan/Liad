Documentação do Desenvolvedor

Bem-vindo à API de referência da LIAD. Integre nossa IA de processamento de linguagem natural ao seu e-commerce para criar uma experiência de venda guiada e acessível por voz e texto.

# Autenticação via API Key

Conforme especificado no requisito RF14, todas as requisições enviadas para a nossa API pública precisam conter a chave única do lojista incluída nos headers HTTP de autorização. Requisições malformadas retornarão HTTP 401 Unauthorized.

Authorization: Bearer seu_token_liad_aqui

# Integração do Widget (RF15)

Para habilitar a interface de chat responsiva com suporte a Text-to-Speech (Acessibilidade) diretamente na sua vitrine virtual, copie e cole o script abaixo antes do fechamento da tag </body>: 

<!-- LIAD Widget Script -->
<script 
  src="https://cdn.liad.ai/widget.js" 
  data-key="sua_api_key_aqui"
  defer>
</script>

Endpoints da API

POST /v1/catalog/csv RF12 - Schema Validator

Permite a ingestão em massa e atualização do catálogo da loja via arquivo CSV estruturado. O motor valida o schema e processa as atualizações em até 5 minutos.

Content-Type: multipart/form-data
POST /v1/catalog/json RF13 - Webhook Sync

Sincronização em tempo real via objetos JSON para ferramentas ou ERPs externos integrados pelo desenvolvedor. 

{
  "products": [
    { "id": "1092", "name": "Notebook Pro", "price": 4500.00, "category": "Informática" }
  ]
}
POST /v1/recommend RF07 / RF08

Endpoint consumido pela interface para interpretar a linguagem natural do usuário final (texto ou voz processada) e retornar uma lista ranqueada de 1 a 5 produtos acompanhados por justificativa descritiva. 

// Request Payload
{
  "prompt": "Quero um computador bom para estudar engenharia de software até 5000 reais"
}
